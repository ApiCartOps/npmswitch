---
description: Check a package's health (usage /npm-package-health name)
argument-hint: package-name
---
Check the health of the npm package $ARGUMENTS using the npmswitch MCP server. Call `npm_get_package` and `npm_downloads`. Report the latest version, dist-tags, last publish date, maintainers, license, deprecated versions and weekly downloads, and flag anything stale or risky. Do not change anything.
